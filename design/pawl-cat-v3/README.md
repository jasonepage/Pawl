# Status: archived cat-heavy exploration

This directory records the first real-cat art-direction exploration. The character model
is useful brand reference, but the style frames overstate the cat and understate Pawl's
actual differentiator: a physical FIDO2 security key.

Do not implement these frames directly. The current direction is documented in
`docs/21_Pawl_Art_Direction.md`:

1. physical security key first;
2. protection state and time second;
3. Pawl as a fixed supporting brand mnemonic;
4. no implied customization or virtual-pet feature.
