# Pawl onboarding art

Five production illustrations generated on 2026-11-02 for the onboarding flow. The set matches the warm, hand-painted 2D editorial treatment used by the existing Unlock art and keeps the modern forest-green USB-C security key as the product.

## Export convention

Each scene is supplied as transparent PNGs using the iOS filename convention:

- `onboarding-*.png` — 1x, 512 × 341
- `onboarding-*@2x.png` — 2x, 1024 × 683
- `onboarding-*@3x.png` — 3x master, 1536 × 1024

Scenes: `welcome`, `screentime`, `choose`, `unlock`, and `lockin`.

## Prompt set

Shared direction: Pawl iOS onboarding illustration; exact 1536 × 1024 horizontal master; supplied Unlock paintings used as style, character, and security-key references; one mature brown-gray tabby with green eyes; one generic forest-green USB-C FIDO2-style key where requested, with a silver USB-C plug, ivory circular touch area, dark-green paw mark, and lanyard hole; warm hand-painted 2D editorial finish; transparent background; clean small-size silhouette; no text, phone, UI, antique key, brass key, collar, clothing, watermark, extra animals, or unrelated props.

- **Welcome:** upright calm cat, eyes open, key prominent in front of its paws.
- **Screen Time:** upright cat holding up one paw in a plain crossing-guard gesture; no key.
- **Choose:** cat looking at three blank rounded app tiles and tapping one; no key.
- **Unlock:** equal crop-safe options separated by a transparent center gap—key alone on the left, sleeping cat with an identical second key on the right.
- **Lock in:** relaxed cat, eyes closed, key tucked under its chin and still clearly visible.

Generated with the built-in image tool. The 1x and 2x exports are Lanczos reductions of each 3x master.
